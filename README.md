# Deepak Dongare — Portfolio

Personal portfolio site for **Deepak Dongare**, IT Manager (Identity & Access
Management and Data Security) at RealThingks GmbH, Pune.

React 19 + Vite + Tailwind, with framer-motion driving a scroll-pinned hero.

## Run it

```bash
npm install
npm run dev      # opens dev.html with HMR
```

| Script            | What it does                                                     |
| ----------------- | ---------------------------------------------------------------- |
| `npm run dev`     | Dev server with hot reload                                        |
| `npm run build`   | Production build, then copies it to the repo root for GitHub Pages |
| `npm run preview` | Serve the production build locally                                 |
| `npm run lint`    | oxlint over `src/`                                                 |

### Why `dev.html`

GitHub Pages serves this repo from the branch **root**, so the built
`index.html` and `assets/` have to live there and stay committed. If the Vite
source entry were also `index.html` the build would overwrite its own source
every time. Keeping the source entry as `dev.html` means `npm run dev` gets
real HMR while `npm run build` publishes to the root untouched
(`scripts/publish-root.mjs`).

## Structure

```
dev.html                  Vite source entry (development)
index.html                built output — committed, served by GitHub Pages
assets/                   built JS/CSS/fonts/images — regenerated by the build
src/
  data.js                 every piece of content on the site
  index.css               design tokens, grain, gutters, iPhone safe areas
  components/
    Hero.jsx              scroll-pinned portrait + kinetic type
    Loader.jsx            0→100% intro
    Navbar.jsx            sticky bar + full-screen mobile menu
    About.jsx  Stack.jsx  Stats.jsx  Experience.jsx  Projects.jsx  Contact.jsx
    Reveal.jsx            scroll reveals (incl. word-by-word masks)
scripts/publish-root.mjs  copies dist/ to the repo root after a build
```

## Editing content

All copy, skills, roles and projects live in **`src/data.js`** — nothing is
hard-coded in the components. The three giant words that swap across the hero
are the `kinetic` array; each is auto-sized to fit the viewport, so longer
phrases still work.

## Photos

`src/assets/deepak-cut.webp` is the background-removed cutout used in the hero.
`src/assets/deepak-portrait.webp` is the framed shot in the About section. To
swap either, replace the file and keep the name.

## Notes

- Light, warm palette throughout; the Projects section is the one dark block.
- Respects `prefers-reduced-motion` — all scroll choreography flattens.
- Built and checked at 1440×900 and iPhone (393×852), including safe-area insets.
